# places.html — Pob's Places

Mode: Experience. Personal layer; private test run (noindex, unlinked), intended to go live later. Audience: friends, peers and curious visitors. Job: see everywhere Pob has been since 2015 on the embedded My Maps map, with the story around it. Avoid: dashboards, anything echoing worldtour.html's dark planetarium. Data: aggregates only (no addresses), personal places filtered by `visited-places/timeline.py`.

## Direction contract

THESIS: Eleven years of places as a passport. Refuses the travel-map page (big map, stats strip, intro).
OWN-WORLD: Navy leather cover framing sage guilloche visa pages; gold foil cover caps (Cinzel); Public Sans fields; JetBrains Mono MRZ; rubber-stamp inks per continent (violet, red, blue, green, brown, teal) with ink-texture filters.
STORY: Open the passport, read the data page, see the map as a visa, browse 77 entry stamps, tap one and the map flies to that country.
FIRST VIEWPORT: Open spread on the navy cover: the left data page (Pob's Places, holder, figures, MRZ); the right page is the map set in as a visa sticker.
FORM: Passport Pages, my own #1 (the pick); seed f0441456.
FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance
